First release of Studywise Courses.

Make a course for a module, then add each week's slides, lecture transcripts and readings. Claude splits every week into topics and teaches each one in short sections: a screen of notes (with the slide itself when it helps), a few quick questions, then the next bit. Each topic ends with a check, and its recall cards pop up while you learn other topics and in spaced review.

Everything from Studywise is still here: notes and flashcards from a PDF, Learn mode, and spaced repetition.

Download `Studywise-Courses.dmg` for Mac (Apple silicon and Intel) or `Studywise-Courses-Setup.exe` for Windows.

You need Claude Code installed and logged in first:

```
npm install -g @anthropic-ai/claude-code
claude
```

The app isn't signed. On a Mac, right-click it and pick Open the first time. On Windows, click More info, then Run anyway.

The Windows build hasn't been tested on a real Windows machine yet.
