## What's new

**Easier course topics and notes.** Topics and the default notes prompt assume you haven't seen the material yet: the plain meaning before the formal definition, why it matters, slide examples cut down and walked through, "Common mistake" callouts, side-by-side tables for ideas that are easy to mix up, links back to earlier topics, and a short exam summary at the end.

**"I don't get this" and rewrite.** Under each section of a topic, "I don't get this" opens Explain with just that section. The rewrite button in the topic header writes the topic again, with an optional note on what to change.

**Skips non-examinable content.** Notes, flashcards and courses leave out anything the material marks as not examinable, and keep anything unclear. Built-in prompts you haven't edited pick up new wording automatically.

**Cheaper planning.** Course topics are planned with Sonnet by default (writing a topic still uses Opus), and PDFs for notes and cards go in 20-page chunks instead of 8, so fewer calls are made.

**Tidier library.** Decks and the Notes sidebar group things under folders that collapse, and remember which are collapsed. Markdown tables fill their box.

**Updates keep your data.** Run the new installer over the old one: it updates the app and leaves your library alone. The first time a new version starts, it saves a copy of your database in the `backups` folder before changing anything.

## Download

Windows: download `Studywise-Courses-Setup.exe` and run it. If you already have Studywise Courses, it updates in place and keeps your courses, decks and progress. On a Mac, build it from source with `npm install && npm run dist`.

You need Claude Code installed and logged in, or an Ollama server or Ollama Cloud key:

```
npm install -g @anthropic-ai/claude-code
claude
```

The app isn't signed. On Windows, click More info, then Run anyway.
